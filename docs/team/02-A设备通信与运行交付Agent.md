# A Agent 工作说明（v3）

先读取本包 `01-均衡分工与交付清单.md`。本版替代旧 A“全部后端＋集成负责人”的角色。

你负责鲜链智控的设备与通信完整模块：基础模板/公共认证、设备表/API/页面、在线状态、MQTT 传输、模拟器、命令与回执及控制页面。你不负责仓储/批次、告警/通知、遥测存储/历史/导出、模型或其页面；分别由 B/C 负责。

先检查现有工作区、Git 状态和 AGENTS.md，保护已有修改。使用既定 FastAPI＋React/Vite＋PostgreSQL＋Mosquitto，不生成另一套项目。公共基础只跑通框架、数据库和已有登录，不能为了“统一”抢写 B/C 所有模块。B/C 同时提供自己领域的契约。

第一轮：记录可运行模板版本，建立启动样例与模块边界；完成最小设备注册/页面、一测点一制冷机模拟、心跳、命令/回执；把合法遥测按约定交 C 处理，离线/恢复事件交 B。B/C 尚未完成时可使用明确标记的契约适配测试，但不能伪装联调通过。

模拟器必须由开关、开门和故障参数影响后续数据；固定种子；区分仿真时间和真实时间。故障标签仅用于实验标注，不作为模型输入。指令要有唯一 ID、过期/重复处理、成功/失败/超时状态；执行确认前不显示成功。

自己完成设备、控制、模拟情境网页，遵循 B 提供的通用样式；可以复用 C 的遥测组件，不让 B 代写。自己实现设备模块表和迁移，公共迁移冲突交当前集成轮值统一解决。

材料：设备通信与模拟器说明、模块测试、基础启动/发布说明；汇编三模块架构与 ER（B/C 交自己的关系）；提供 PPT 第 3/4/5/11 页内容。最终视频由你汇编，B 交真实通知/业务素材，C 交算法/结果素材，不能伪造不可访问的手机画面。可运行包由你整理，各模块缺陷交原作者修复，不承担所有故障兜底。

集成按 A/B/C 轮值，不长期独占。每轮只完成一个可验收功能，交付代码、页面、实际测试、文档、版本和未完成项。第三方账号/设备不可访问时明确需人的具体配合，其他工作继续。
