# C Agent 工作说明（v3）

先读取本包 `01-均衡分工与交付清单.md`。本版将模拟器开发从 C 移给 A，你负责数据与算法完整模块。

职责：遥测存储/质量、历史查询/CSV、风险结果与模型的数据库/API/页面、实验数据、算法验证与材料。模拟器由 A 提供，批次规则和通知由 B 提供，不替他们重写。

先检查已有项目与规范，使用同一 FastAPI/Python 和 React/Vite 工程。你自己完成 data/analytics 前端页面及可复用遥测图组件，遵循 B 的样式；不是只交 notebook 等 B 做全部可视化。

第一轮：提出遥测消息与处理/查询接口草案、规则/批次输入需求和测试情境；核查品种资料；实现最小原始数据存储、去重、查询和图表。A 上报按入口接入后，数据必须实际落库；B 从结果收到可追溯异常候选。未完成模型时先用固定阈值联调，并如实标注。

清洗处理字段、单位、无效值和缺失，保存质量标记；不能删除真实升温。窗口不足/长缺测不能判低风险，在线计算不使用未来观测。实现批次累计越界暴露，依据 B 的在库区间/规则快照；恢复后历史不清零，不宣传真实腐败概率。

实现 Isolation Forest、正常工况训练、独立情境验证/测试与基线比较；通过 A 模拟器稳定接口生成实验，故障标签不进输入，报告实际样本量、漏报、误报和延迟。模型、阈值、数据版本和图表一致。历史筛选/导出按时间单位和质量规则验证。

材料：算法设计报告、关联源码/调用说明、数据样本与来源/生成规则/样本量/划分、复现流程、数据算法章节和测试；提供 PPT 第 7/8/9/10 页及视频算法素材。汇编全队测试报告时只汇编 A/B 交付的实际证据，不替他们全部手测，不补造通过结论。软件文档主编归 B，视频主编归 A。

每人自己写所属表与迁移，公共冲突由轮值集成处理。按 A/B/C 轮值接力集成；每轮交代码、页面、实际测试、文档、版本、问题与下一步。缺模拟器功能向 A 提出明确情境与输入输出，不私建第二套设备系统。
