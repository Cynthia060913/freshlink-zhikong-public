# Public 候选流水线默认安全边界

2026-10-14迁移已获批准，远端代码完整性已核对；当前协作切换和CI结果仍见
PUBLIC-MIGRATION.md 与新库 #1，不以本说明代替实际运行。

- 校赛CI沿用标准 ubuntu-latest 后端、Compose、浏览器、规范和安全检查，
  不新增付费大型runner或自托管开发机，不跳过覆盖率90%门禁。
- 两个继承的部署job仅在维护者明确设置 `ENABLE_DEPLOYMENT=true` 后才能
  执行。默认不部署、不连接正式库、不使用自托管runner。不得为CI红灯
  设置该变量或填写真实生产密钥；首次部署必须单独获得用户授权。
- 第三方覆盖率外传Smokeshow默认禁用，只有经授权设置
  `ENABLE_EXTERNAL_COVERAGE=true` 才运行。后端本地生成/保存覆盖率及其
  90%门禁仍运行，不将跳过外传称为测试通过。
- 默认不上传Actions报告附件，避免共享artifact存储额度产生额外费用。
  仅显式授权并设置 `ENABLE_CI_ARTIFACTS=true` 后上传覆盖率HTML、浏览器blob
  并生成合并HTML；普通后端90%门禁、浏览器四分片断言和结果聚合仍运行，
  可从Actions日志查证。附件关闭不算跳过测试，也不保证浏览器已通过。
  若以后开启，HTML保留3天、blob1天；不得在报告/截图中使用真实秘密。
- 公开标准runner运行时间免费不等于所有存储/服务都没有费用；不提高
  付费预算或缓存限额，首次运行检查实际存储和Actions是否启动。
- 继承的 pull_request_target 任务仅处理元数据且不检出PR代码；仍须保持
  只读检出、不运行外来PR代码的写权限上下文，不给匿名贡献者密钥。
- 新仓库配置允许的Actions、fork首次运行审批与主分支评审保护需另按
  实际GitHub权限核验。三位可写，外人可以提PR但不能直接改受控分支。

文件只记录默认开关和待核验范围，不授权部署、付款、外发或合并未经审查
的B/C模块。迁移时必须更新真实main和新Issue入口，不复制旧私人评论。
