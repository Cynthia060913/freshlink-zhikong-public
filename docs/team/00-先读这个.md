# 鲜链智控：Agent 开发分工 v3

本版替代之前按“一个人负责全部后端、一个人负责全部前端、一个人负责模拟器与算法”的分工，以及 v1/v2 中的人员、材料和集成归属。旧文件保留供查阅，但不要混用其角色提示词。

项目不变：**鲜链智控——面向农产品冷链仓储的品质风险评估、异常预警与智能调控平台**。

本版适用条件：三个人、三台电脑，代码、测试和材料尽量由各自 Agent 执行；成员不按队长身份或手写代码强弱划分。

新分工：

- A：设备与通信，包括设备模拟器、设备注册/状态、控制/回执、对应页面；基础运行与交付包；视频成品。
- B：仓储与告警，包括冷库/批次、告警/处置、两种通知、对应页面；软件设计文档汇编；PPT 成品。
- C：数据与算法，包括遥测存储、清洗、历史/导出、风险和模型、对应页面；算法与数据材料；测试报告汇编。

每位 Agent 对自己的功能同时负责页面、接口、数据表、测试和文档，使用同一个后端与前端工程，不创建三套系统。复杂跨域接口先共同确定；运行问题按所属模块返给原作者修复，日常集成轮值。

阅读 `01-均衡分工与交付清单.md`，然后分别使用 A/B/C 工作说明。启动时三位 Agent 都应收到总分工文件和自己的角色文件，并访问同一代码仓库。

原项目范围保持：两个冷库、三个同品种批次、十四逻辑设备；纯软件模拟；Isolation Forest＋阈值基线＋可解释批次环境暴露；邮件和第三方 Android 推送作为优先验证路线，其验收口径尚需组委会确认。

本文件包是实施规划，不是已经完成的软件、测试报告、PPT 或视频。公共基础用一个短阶段先跑通，之后三人并行。无需为本方案启动三个远程服务或购买三台云服务器。
