# 安全录屏与隐私遮挡检查

依据固定提交 `96afaab8ef5a26725a0fa31ff4ff3fc4983698bf`。本页只给 A 录制/导出前、中、后
的可操作检查，**不读取真实秘密、不登录邮箱、不自动录屏、不对外上传**。所有真实收件证据
先脱敏再进素材，原始件只留在私有 `work/`。

## 1. 录制前检查（逐项过）

- [ ] 关闭或退出不相关应用，把桌面可见的个人文件**隐藏或切换到干净桌面**、关闭聊天窗口与
      浏览器无关标签页；**绝不删除**任何个人文件。
- [ ] 检查要录的页面不含：邮箱完整地址、手机号、真实姓名/学号、个人目录路径（如
      `C:\Users\<名字>`）。
- [ ] 检查终端窗口：不露出 `FRESHLINK_*_PASSWORD`、`POSTGRES_PASSWORD`、`SECRET_KEY`、
      SMTP 授权码、飞书机器人 hook/secret、Token 等环境变量或命令历史。
- [ ] 检查配置文件：`.env.freshlink`、`runtime.*.json`、`work/` 下的私有配置不进入画面。
- [ ] 检查二维码：飞书/登录二维码**不进镜头**，需要用则不露出可识别图案。
- [ ] 检查浏览器通知/扩展图标与地址栏，确认不显示登录态账号头像/邮箱。

## 2. 录制中检查

- [ ] 只录业务页面（`/devices`、`/telemetry`、`/alerts`）与脱敏后的收件证据，不切到配置编辑器。
- [ ] 需展示收件证据时，先遮挡：邮箱前缀、手机号、授权码、机器人地址、二维码、发件签名；
      保留“事件关联”所需的最小信息（时间、渠道、脱敏标题/摘要）。
- [ ] 输入密码/密钥时停录或打码；用“演示账号 + 本机私有密码”时也不在画面显示密码明文。
- [ ] 口头说明与画面一致，不念出真实账号或密钥。

## 3. 导出后检查

- [ ] 回放一遍，逐帧确认没有意外入镜的隐私（通知弹窗、悬浮头像、文件管理器路径）。
- [ ] 检查导出文件名/元数据不含真实姓名、学号、邮箱、路径；需要时用脱敏文件名。
- [ ] 上传前跑一遍文本/画面复核，把原始素材与脱敏成品分目录放，原始件只存私有 `work/`。
- [ ] 收件证据保留“事件关联”：同一告警事件 → 通知 attempt → 邮箱/飞书实收三者用同一
      来源 ID/时间对应，但隐藏可识别个人身份的字段。

## 4. 公开素材脱敏 vs 正式参赛包名（两回事）

- 公开素材/视频画面里的私人信息要**脱敏**：遮挡账号、授权码、二维码、手机号等。
- 但**正式参赛包名是通知要求**，外层包名必须保留 `赛道号_学号_姓名_项目名称`；不能为了脱敏
  删掉这些必需字段。身份信息由本人提供并填入，不由本工具代填、代删或代改。

## 5. 不做的

- 不读取或打印真实密钥/授权码/机器人 secret；不登录邮箱或飞书账号取件。
- 不自动录屏、不上传、不发通知；不替 B 制作或覆盖 PPT。
- 不把“服务端已提交/已接受通知”当作终端实收，不拿伪造截图冒充实收。
