# 源码候选包：固定版本导出与逐字节验证

这是 M01 的准备工具，不是最终参赛发布或完整安全审计。使用已有 Git 和
PowerShell/.NET（优先已验证的 PowerShell 7），不安装、卸载或修改 Python，不访问网络/数据库，
不上传、不发送、不删除任何旧输出。三位可各自在自己的新库目录运行。

```powershell
$taskSourceRevision=(git rev-parse HEAD).Trim()
# 先确认这是准备核验的完整40位提交号；脚本不会在中途改用别的“最新版”。
.\scripts\windows\export-source-candidate.ps1 -Revision $taskSourceRevision
```

先审查并选定完整版本，再导出。不要把自己未提交的工作或本机配置混进包。
工具仅导出该提交的已跟踪普通文件，保留已核对的根 `.env` 与 `frontend/.env` 模板，拒绝已跟踪的真实配置、
私有目录/数据库/私钥类路径、非普通文件、Windows 路径冲突或超出大小边界。
未跟踪的配置与日志不会被复制，也不会为检查它们而读取其内容。
这两个 `.env` 只允许共同 e235 基线已审核的确切 blob；若后来改过，先失败并
要求人工复核，不能只凭文件名叫“模板”就把新填的密码打包。复核后再更新白名单。

每次输出在 `work/source-candidates/` 新建唯一子目录：候选 ZIP、实际解包目录、
`manifest.json`。核对 ZIP 成员/大小、实际解包后的每条 Git blob 与 SHA256；
中文路径也按完整名称核对。仅对本次导出固定 LF，不修改用户 Git 换行配置。
任何省略、格式转换或差异均失败，不悄悄放宽校验。失败输出私下保留，不能发送。

清单还包含固定来源版本、ZIP 哈希、非英文路径数及未做文本扫描的二进制数。
有限凭据模式检查不覆盖全部秘密、个人信息、许可证、历史或媒体内容；**通过
仍须发布前人工复核，不代表“允许公开”或 M01 已签收**。

运行工具回归：

```powershell

```

回归只在 `work/` 新建合成 Git 仓库，验证中文/二进制、换行、未跟踪私有配置
排除、重复运行不覆盖、未知SHA/已跟踪私有配置/变更过的模板/构造凭据拒绝。构造测试值不是真实
令牌。回归不改真实仓库配置或历史；测试证据也保留，不自动清理。
