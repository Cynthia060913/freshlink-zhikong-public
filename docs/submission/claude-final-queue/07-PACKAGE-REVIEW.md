## 3. 镜像交付的明确说明

- 镜像 ID（G4 `sha256:3a09d10c…`）与 `application-build.json` 是来源声明，**不是**可运行交付物。
- 实际交付 M02 还需要：镜像归档（或获准获取途径）+ 启动/配置说明 + 依赖（含 build-system 联网
  条件）；当前没有现成镜像导入脚本，这一环是待补缺口（见 04）。

## 4. 包名与隐私的两条边界

- 正式外层包名保留 `赛道号_学号_姓名_项目名称`，身份由本人提供，不编造、不代删。
- 公开示例与画面里的私人信息脱敏（遮挡账号/授权码/二维码/手机号/完整收件地址）；脱敏是
  公开素材的事，不等于删除正式投递包名的必需身份字段。

- [ ] 无秘密/私有日志/数据库；模板无可用真实密钥。
- [ ] M01—M05 成品签收；启用算法才交 M06—M08。
