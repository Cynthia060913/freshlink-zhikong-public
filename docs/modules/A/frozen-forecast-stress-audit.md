# 固定温度模型补充仿真验证

## 目的和方法

本验证扩大已发布模型的适用条件检查，不重新训练、修改参数或选择提示余量。
原始训练、确认集和“不启用业务提前预警”的结论保留。模型仍为
`c-ridge-synthetic-v1`，参数规范摘要为
`631c342435be05626f4ddafc648984091d9a317a803ffe2ee652d324ab5a7ec8`。

运行前先写出独立计划文件，保存场景、种子、数据规则、指标和比较条件；本次计划
按 UTF-8 和 LF 规范表示的 SHA256 为
`bf0815d29c22fb5454b2ac44ceb1ea42c9e2900125156105ae3a17983757c75d`，避免
Windows 检出换行影响同一计划的身份。
数据包含稳定远阈值、稳定近阈值、持续升温、突变升温、降温五类，各 10 条运行，
每条 600 秒，每 5 秒采样。噪声、缺测、坏质量和迟到概率在计划中明确。
50 个种子及观测身份与原 75 条训练／验证／测试／确认运行分离。

所有方法使用相同的生产输入守卫、120 秒历史和 60 秒目标；先按 received_at
截断未来到达，再检查质量、归属、时效和缺口。参数只读，不进行模型搜索。
本文所有温度和业务扰动均是软件仿真；8°C 仅为评价阈值，不是实际苹果仓储标准。

## 全量结果

2100 次预定决策中 1290 次可计算（61.43%）；其余 724 次采样缺口、78 次质量阻断、
8 次过期。误差仅以相同的 1290 个有效窗口计算，拒绝的 810 次不当作零误差。

| 方法 | MAE °C | RMSE °C | 新超限检出 | 假提示段数 | 假提示决策数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 末值保持 | 0.1809 | 0.2631 | 0/16 | 0 | 0 |
| 线性趋势 | 0.1453 | 0.2533 | 9/16 | 26 | 63 |
| 固定岭回归 | 0.1268 | 0.2461 | 9/16 | 26 | 66 |
| 固定岭回归加原 0.1°C 提示余量 | 0.1268 | 0.2461 | 9/16 | 17 | 45 |

提示余量只影响离线提示判定，不改变预测数值，因此最后两行的数值误差相同。
它不是本次新增的在线预警策略。假提示段将相邻 10 秒决策合并；完整结果同时保留
逐次决策数和分母，不能把两个口径混用。

| 场景 | 线性趋势 MAE °C | 岭回归 MAE °C | 原余量方案检出 |
| --- | ---: | ---: | ---: |
| 稳定远阈值 | 0.0874 | 0.0618 | 无新增超限事件 |
| 稳定近阈值 | 0.1018 | 0.0838 | 无新增超限事件 |
| 持续升温 | 0.0833 | 0.0595 | 9/10 |
| 突变升温 | 0.3535 | 0.3488 | 0/6 |
| 降温 | 0.0879 | 0.0674 | 无新增超限事件 |

稳定和缓变场景支持把模型作为短时数值参考；突变场景没有提前检出能力。
传感器尚未观测到的突变无法仅靠历史曲线预知，原阈值告警必须继续独立运行。
本次仿真数值改善不等于现场保鲜、节能、经济收益或更可靠的自动预警。

本补充集将“新增事件”定义为从低于 8°C 上穿且连续保持至少 10 秒，初始已超限
不计新增事件；原确认集采用首次上穿口径，故两组事件分数不直接合并。
原确认集只有 5 个新增事件，原余量方案检出 2/5 的失败事实不被本次 9/16 覆盖。
本补充集的比较条件虽通过，整体业务提前预警仍不采用。

## 复现与数据

从 backend 执行（Python 3.14，复用项目依赖，不修改宿主 Python）：

```text
python -m experiments.c_forecast.audit_frozen_model --plan experiments/c_forecast/artifacts/a-audit-v1/plan.json --output NEW_DIRECTORY
python -m unittest experiments.c_forecast.test_frozen_audit -v
```

输出目录必须不存在，防止覆盖原结果。运行生成全部观测、每秒仿真真值、逐运行结果、
清单和样本。两次无网络容器运行的全部五个数据／结果文件字节摘要一致；完整原始
观测 1965766 字节、真值 573702 字节，对应摘要见清单。提交源中保留脚本、固定参数、
计划、逐运行结果、100 条样本；完整生成数据另外随算法材料保存。

3 项纯方法检查实际通过：新种子与确定性、未来到达不影响历史输入、事件与假提示
计数口径。该实验不访问数据库、控制或通知，也不等于应用端到端或现场试验。
