## 实现与边界

- 专用干净 Session 锁定设备，重读当前身份，验证非保留、新鲜心跳；
  状态、首次消息指纹和离线/恢复事件在同一 PostgreSQL 事务提交。
- 重复、同 ID 内容冲突、乱序不续在线；冲突变体保留独立证据。提交失败
  全部回滚，异常上抛；不提交调用者其他待写对象。
- 未见心跳为 unknown；超过90秒记录稳定 offline 来源；恢复引用该来源。
  扫描并发串行，漏扫后的新心跳保留离线和恢复两条事件。
- A02 继承 A01，不覆盖旧设备字段。旧 last_seen 不足以建立可信 online。
  数据库约束禁止无完整心跳历史的 online/offline 和错误离线引用。
- 登录用户可查 `/api/v1/devices/{id}/connectivity-events`，分页上限100。
  当前页面5秒刷新、显示最近5条事件及关联ID；未绑定事件 held_unbound，
  已绑定事件 pending。没有对外投递器；delivered 也不得解释为通知实收。
- 接收函数要求可信 Broker/ACL 适配先完成认证。没有匿名/普通用户可写
  心跳的 HTTP 入口；生产 MQTT 监听器尚未接线。
