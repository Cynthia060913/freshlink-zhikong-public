# C 短时温度预测：独立仿真对照首轮结果

状态：**实验候选，未进入应用业务链**。此报告全部数据由本分支生成器产生，不是真实冷库测量、保鲜/节能收益，也不改变无算法保底包。模型参数固定为 `c-ridge-synthetic-v1`；当前结果不足以宣称岭回归的提前关注业务效果优于线性趋势。

## 先固定的问题与划分

- 在决策时刻 `as_of`，只用同设备/冷库且服务器已收到、质量为 `ok` 的过去120秒温度，预测 `as_of+60秒` 的摄氏温度。历史选择复用 PR103 候选门槛的**实验镜像**：至少8点/10秒跨度、最新15秒内、相邻缺口至多10秒；过期、缺口或最新质量错误时拒绝。最终系统接入必须改用 A 正式守卫再复核，实验镜像不当正式生产选择器。
- 三种方法接收完全相同的可用窗口和目标：最后值、窗口最小二乘线性趋势、标准化四特征的岭回归。岭回归仅在训练集拟合均值/尺度、系数，固定惩罚 `lambda=1.0`；本轮没有用验证或测试调参，也没有第二轮选择。运行推理仅用 Python 标准库和可校验 JSON 参数，无重型运行依赖。
- 完整60条虚拟运行：稳定/逐渐升温/制冷降温各20条，0—600虚拟秒、每5秒采样。各场景索引00—11训练、12—14验证、15—19测试，即36/9/15条完整运行；随机种子和设备ID不跨集合。所有相邻时刻留在原运行，不逐行随机拆分。每次决策从130至540秒、间隔10秒；未来真实轨迹只作60秒后标签，未来接收的观测先从历史输入排除。
- 固定仿真规则：场景漂移、0.09℃高斯测量噪声、7%缺测、4%质量错误、12%迟到20—80秒，以及每运行一次在未来随机时刻出现的 -0.25 至 +0.55℃不可预知扰动。参数、种子、运行ID及完整原始合成观测文件哈希见 `backend/experiments/c_forecast/artifacts/v1/manifest.json`。仓库仅提交其中60行脱敏格式样本；完整合成数据由下方命令生成，防止把大数据文件当人工真实观测。

## 实跑结果（测试集，只评价一次）

本机 Windows 的隔离 Python 3.13 标准库运行。项目正式应用要求 Python 3.14，本轮**未在本人电脑以3.14或真实PG/HTTP复测算法**。36训练运行得到880个可用窗口，9验证运行225个；15测试运行共有630个决策，397个可用（覆盖率63.02%），233个拒绝：采样缺口204、最新质量错误26、过期3。拒绝窗口没有预测值，也不判正常。

| 方法 | 测试MAE（℃；同397窗口） | 正确提前发现/实际新超限事件 | 正确事件提前量中位数 | 误报决策/可比较的阈值以下窗口 |
|---|---:|---:|---:|---:|
| 末值 | 0.2858 | 0/5 | 不适用 | 0/302 |
| 线性趋势 | 0.1305 | 2/5 | 21.5秒（2件） | 15/302 |
| 岭回归 | 0.1184 | 2/5 | 26.5秒（2件） | 17/302 |

提前关注定义：当前最新可用观测低于8.0℃，预测达到8.0℃，并在后续60秒真实轨迹首次从低于阈值越过阈值。事件按**完整运行**计一次；测试集5个新越界事件都在升温运行，另10条稳定/降温运行没有新越界事件，因此这两个场景的事件召回率**不适用**，不能写0%或100%。正确事件取该60秒窗口内最早正确提示到越界的秒数；误报按可比较决策计数，并非独立误报事件数。未提前发现的3件照实计入漏报。原阈值告警作为独立业务链保留，不能用提前候选代替或压制。

分场景的可用窗口与MAE：稳定101（末值0.0995、趋势0.1477、岭0.1318℃）；升温146（0.3846、0.1253、0.1094℃）；降温150（0.3151、0.1238、0.1181℃）。岭回归在稳定场景反而不如末值，稳定场景误报16/100（趋势14/100）。因此虽然岭回归总体MAE比趋势低0.0121℃，**业务事件召回没有提高，误报多2个决策**；本数据量只有5个新越界事件，不能据此宣传“提前预警显著有效”。候选默认门槛在有缺测时拒绝较多，需以正式守卫和后续独立数据评估覆盖率。模拟器规则和扰动均由代码已知，结果不能外推到真实库房。
