## 0. 当前起点与最终目标

A 本机已通过 Docker 构建、数据库/应用健康检查、API 登录检查，且用户提供实际登录后的首页截图。B/C 两台电脑能否启动未知；团队远程仓库未建立。冷链业务和算法尚未验收。

固定项目：鲜链智控——面向农产品冷链仓储的品质风险评估、异常预警与智能调控平台。两冷库、三批同一明确品种苹果、十四逻辑设备：每库两个温度测点、一个湿度测点、一个门磁、主/备用制冷设备和一个电表。纯软件仿真合法，界面和报告明确标注仿真来源，不安排 PCB/硬件采购。

最终必须是一套能从设备上报走到异常处置、控制反馈和追溯导出的程序，而非三套互不关联的页面。算法为我们主动选择的加分项，做了就交完整关联代码、报告和数据材料。不能保证名次，以实际完整性、证据和答辩提高竞争力。
